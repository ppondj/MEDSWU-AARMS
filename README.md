# MEDSWU-AARMS · ฉบับติดตั้งลงหน้าจอโฮม (iPad / iPhone / เบราว์เซอร์)

ระบบลงทะเบียนและบันทึกการเข้าร่วมกิจกรรม คณะแพทยศาสตร์ มหาวิทยาลัยศรีนครินทรวิโรฒ · รุ่น 1.8.0

ไฟล์ในที่เก็บนี้คือโปรแกรมฉบับเว็บที่เปิดผ่าน GitHub Pages แล้วติดตั้งลงหน้าจอโฮมของ iPad ได้
**ข้อมูลทั้งหมดเก็บอยู่ในเครื่องที่ใช้งานเท่านั้น** ไม่มีการส่งข้อมูลมาที่เว็บไซต์นี้หรือที่อื่น
(เว็บไซต์มีเพียงตัวโปรแกรม)

## ติดตั้งบน iPad

1. เปิดที่อยู่ของเว็บไซต์นี้ด้วย **Safari**
2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen) → เพิ่ม
3. เปิดโปรแกรมจากไอคอน **AARMS** บนหน้าจอโฮมทุกครั้ง

ข้อมูลที่ใช้ในซาฟารีกับข้อมูลในแอปบนหน้าจอโฮมแยกกัน ให้ติดตั้งก่อนแล้วจึงเริ่มใช้งาน
หลังเปิดครั้งแรกแล้ว โปรแกรมเปิดได้แม้ไม่มีอินเทอร์เน็ต

## การใช้งานบน iPad

- **พิมพ์**: แตะ "พิมพ์" ในหน้าพร้อมพิมพ์ แล้วเลือกเครื่องพิมพ์ AirPrint · ตั้งขนาดกระดาษให้ตรงกับแบบ และพิมพ์ 100%
- **บันทึก PDF**: ในหน้าต่างพิมพ์ แตะปุ่มแชร์ → บันทึกลงในไฟล์
- **ไฟล์ที่ส่งออก** (Excel, สำรองข้อมูล ฯลฯ): แตะ "บันทึกไฟล์" → บันทึกลงในไฟล์ / AirDrop / Mail
- **กล้อง**: อ่าน QR Code และบาร์โค้ด และถ่ายภาพบุคคลได้ (อนุญาตการใช้กล้องเมื่อระบบถาม)
- **เครื่องสแกนบาร์โค้ด Bluetooth**: จับคู่กับ iPad ในโหมดแป้นพิมพ์ (HID) แล้วใช้ได้ทันที
- **หน้าจอผู้ลงทะเบียน (Kiosk)**: เปิด "การเข้าถึงแบบมีผู้ช่วย" (Guided Access) ที่ การตั้งค่า → การช่วยการเข้าถึง
  เพื่อล็อก iPad ไว้ที่โปรแกรม

## สำรองข้อมูล

ข้อมูลอยู่ใน iPad เครื่องเดียว หากลบแอปออกจากหน้าจอโฮม ล้างข้อมูลเว็บไซต์ หรือเครื่องเสียหาย ข้อมูลจะหายไป
ให้สำรองข้อมูลแล้ว **บันทึกไฟล์สำรองไว้นอกเครื่อง** (Files / iCloud Drive / AirDrop ไปที่คอมพิวเตอร์) ทุกครั้งหลังจบกิจกรรม
ไฟล์สำรอง (.db) ใช้กู้คืนได้ทั้งในฉบับนี้และในโปรแกรมบนคอมพิวเตอร์
